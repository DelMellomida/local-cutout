# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Report a
vulnerability** form on this repository's Security tab. Include reproduction steps, affected browser
or version, impact, and any suggested mitigation.

Reports are handled on a best-effort basis. You should receive an acknowledgement within seven days.
Please allow time for a fix before public disclosure.

## Supported version

Only the current default branch is supported. There are no long-term-support releases.
